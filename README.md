# Cats_and_Dogs_CNN
image recognition model for 240x240 cats and dogs images from Kaggle cats and dogs dataset

the raw dataset used can be found at https://www.microsoft.com/en-us/download/details.aspx?id=54765&msockid=152e33ac818f6f21253525be806f6e36, however note the training data used in the code was first passed through the dataset_image_processer.py script, resulting in the correct Processed folder which is later accessed to train the model.

-note due to currently low training accuracies due to grayscale training, a pre-trained model is not attached, however on running either of the local trainers (CPU or GPU accelerated) if no model is found it will create a new one, with identical name and format: "CNN_mnist_model.npz" (-note if using the NPZ Viewer vscode extension it may give and error something along the lines of "Error reading NPZ file, stream destroyed", this is normal and I assume to be a product of the size of the model, however the NPZ is still accessible and can still be read and write to. -I hope to be able to post a pre-trained model soon as well as the addition of RGB training data.

-note that in the client code for the Server+Client trainer the server ip (ipv4) address is left out instead replaced with "put the server ip here", this can be found on what is currently line 85 and is stored as the variable HOST, this field needs to be the ipv4 address of the server you are running the server code off of and therefore wish the client to connect via, it also needs to be in string format, an example would be "40.154.7.218", you can find your ipv4 address at https://whatismyipaddress.com/, make sure to use ipv4, once you have pasted your ip address you will need to setup a port forward, this can be done by going into your routers settings (there is usually a website for this depending on provider) and usually under the firewall section select create new Port forward, then use port 5000 for both of the IN ports and both OUT ports and select the local ip of the device you are running the server code on, -Note make sure protocol is set to TCP, as this is what the code uses via python and it will not work without this selected, additionally the rule name does not matter as it is only a way to identify individual rules in the future.
-your ip address also changes generally about monthly on most modern routers so if one day the Server+Client setup mysteriously wont connect, the ip address in the client code being out of date is the most likely culprit, this can be fixed using Dynamic DNS if needed hwover it is usually more work than its worth for training for shorter durations.
-most router consoles can be accessed by typing your ipv4 address into the address bar of any modern search engine, however port forwarding rules are usually blocked behind an admin password, this is generally found on the back of the router

-note that the models are both currently running with grayscale training data as that is how the images where processed in dataset_image_processer.py script, and thus that is what the training code is set up to handle, however due to low accuracies after training I am currently working on a RGB model to hopefully provide more context and increase dataset accuracy.
